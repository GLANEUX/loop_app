# Loop — Front (Expo)

**LOOP** est l'application mobile d'un réseau de mise en relation entre musiciens.

Elle propose :
- authentification des utilisateurs
- découverte par swipe des profils
- messagerie entre musiciens
- gestion des profils (préférences musicales, instruments, extraits audio)

L'app est développée en **React Native + Expo**, avec **Expo Router** et **TypeScript**.
